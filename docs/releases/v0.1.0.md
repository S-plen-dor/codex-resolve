# Codex Resolve v0.1.0

首个正式公开发布版本。通过与Codex自然语言对话，在DaVinci Resolve Studio 21中组织视频剪辑、修改和交付。

## 本版内容

- 轻量剪辑Skill：按需使用工具，不强制风格、固定阶段、JSON计划或阅读顺序。
- 素材规格、精确抽帧、观察包、双机位同步候选与音频特征。
- 可选计划执行：多轨剪辑、静态构图、Fusion动态运镜/透明度及有限慢放。
- 独立音频、增益、淡入淡出及新的PCM工作资产。
- 全片/分段预览，渲染提交、状态查询和实际产物关联。
- 自然语言由Codex理解，工具提供镜头ID定位、计划修订和已认可片段保护。
- 可选项目状态、版本历史、跨聊天交接和审片声明。
- before.drp、editable.drp及生成资产保留，可继续在Resolve编辑。
- 独立安装脚本、Skill复制工具与MIT许可证。

## 下载与安装

下载本Release的Source code并解压，或从仓库检出v0.1.0。需自行安装Codex、Resolve Studio 21、Python 3.12与FFmpeg，并配置Resolve本地脚本连接。

在仓库运行：

```powershell
.\scripts\bootstrap.ps1
```

resolve-edit-v0.1.0.zip仅包含Skill文件，解压到当前Codex支持的Skills目录，或使用安装包的skill-copy命令指定新目录。Skill ZIP不包含Python工具、模型或Resolve。

## 支持范围

首发面向Windows与Resolve Studio 21。当前计划适配器要求视频同帧率、规则时间戳；慢放采用有限的原生实现。异帧率/VFR、复杂抠像、自动跟踪、任意OFX、自动调色、原地增量修改和自动故障恢复尚未实现或验证。Codex可以根据任务选择其他接口或项目专用实现；这些边界不构成创作限制。
