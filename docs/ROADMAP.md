# 开发路线

按成果推进，不承诺固定日期。开发过程是否运行测试遵循当次用户要求；未经验证的能力始终明确标注。

## 已完成的开发基线（未运行验证）

- 独立仓库目录及 Python 包结构。
- 提取基础媒体、同步、歌词、Fusion 和质量工具。
- 去除历史运行库注入和个人路径，独立环境及本地模型配置。
- 自然语言剪辑 Skill、项目记录与只读连接入口。
- 产品定位、能力清单、来源、安装与架构文档。

## 下一里程碑：可执行初稿

- 定稿最小剪辑计划及输入检查；源身份和时间基纳入协议。
- 实现官方 API 时间线执行器：当前目标校验、新工作时间线、素材入轨、连续主音与静态构图。
- 持久化操作记录、工程备份与重复操作识别。
- 渲染编排：任务 id、状态、失败原因及明确新输出。
- 用户可从一句需求得到单机位 20–30 秒初稿与可编辑工程。

## 对话修改与持续工作

- 将自然语言反馈关联稳定镜头 id。
- 计划差异、局部修改、明确版本恢复。
- 保存重开后状态对照与跨对话恢复。

## 场景与视觉扩展

- 同步双/多机位与漂移、异帧率处理。
- 可选视觉 Skills 资产导入、短段验证与明确降级。
- 多场次歌曲/动作分段对应与音乐短片。

## 发布成熟度

后续在用户授权验证时，建立干净环境安装记录、真实项目闭环、合成输入回归、版本兼容矩阵和可授权演示素材。当前不将历史单机通过记录标作新仓库的 CI 或跨机器验收。
