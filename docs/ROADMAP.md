# 开发路线

按成果推进，不承诺固定日期。开发过程是否运行测试遵循当次用户要求；未经验证的能力始终明确标注。

## 已完成的开发基线（未运行验证）

- 独立仓库目录及 Python 包结构。
- 提取基础媒体、同步、歌词、Fusion 和质量工具。
- 去除历史运行库注入和个人路径，独立环境及本地模型配置。
- 自然语言剪辑 Skill、项目记录与只读连接入口。
- 产品定位、能力清单、来源、安装与架构文档。

## 本轮新增实现（未运行验证）

- 素材观察包：粗/密抽帧、名义时间索引、可选带音短片。
- 计划结构检查、可选内容哈希和镜头/音频 ID 差异。
- 原速同帧率多轨计划执行器、静态构图、新时间线、保存/DRP备份、失败操作记录。
- 基于已存在预设的渲染排队、可选启动及状态查询。
- 创作意图模板、审片记录示例及 Skill 编排指导。
- 可选 workspace 自动状态与历史、生成式交接、只读 resume。
- 计划选择、按区间定位片段、精确基础哈希修订与保护已认可 ID。

仅编写代码和静态阅读，未安装或执行命令，未运行测试或连接 Resolve。当前不宣称用户已可稳定从需求得到成片。

## 首版核心链路已编写（未运行验证）

- 可组合camera/opacity与有限原生慢放、独立音频/PCM增益淡化。
- produce一次构建并提交预览，可选先修订反馈；全片和分段、显式尺寸/帧率。
- 实际视频收集/哈希、可选技术QC/观察、审片声明及状态关联。
- before/after可编辑DRP、live结构/属性对照、安装脚本与可分发Skill。
- 命令接口链路已实现，不代表无人值守剪辑或跨机器可靠性通过。完整路径见END_TO_END.md。

## 后续扩展与成熟度

- 异帧率/VFR、任意速度映射及复杂效果适配。
- 执行器跨版本能力探测与源时间映射支持。
- 重开验证、失败恢复、完整工程状态及预览结果回读。
- 完善不同编码器/预设兼容、自动实际结果回读和授权后的运行验证。
- 在授权验证时，以真实项目确认自然语言到成片及修改闭环；不设固定片长。

## 对话修改与持续工作

- 增强语义指代与实际预览证据的对应，保持歧义透明。
- 原地局部执行、明确工程版本恢复和事件重放。
- 保存重开后的 live 状态对照，扩展当前记录级续接。

## 场景与视觉扩展

- 同步双/多机位与漂移、异帧率处理。
- 可选视觉 Skills 资产导入、短段验证与明确降级。
- 多场次歌曲/动作分段对应与音乐短片。

## 发布成熟度

后续在用户授权验证时，建立干净环境安装记录、真实项目闭环、合成输入回归、版本兼容矩阵和可授权演示素材。当前不将历史单机通过记录标作新仓库的 CI 或跨机器验收。
